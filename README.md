# EduRoom - Sistema de Reserva de Cubiculos Universitarios

Este proyecto corresponde al Avance de Proyecto Final 1 (Semana 6) para el curso de Herramientas de Desarrollo. Consiste en una aplicacion web interactiva orientada a la gestion y separacion de salas de estudio dentro del campus, desarrollada mediante un flujo de trabajo distribuido.

## Estructura del Repositorio
* index.html: Estructura semantica del formulario y el contenedor dinamico.
* style.css: Hoja de estilos para la experiencia de usuario y diseño responsivo.
* app.js: Logica interactiva para el registro de reservas y liberacion de espacios.

## Control de Versiones y Metodologia (Segun Silabo)
El repositorio se estructuro siguiendo el cronograma de actividades de las primeras 6 semanas del curso:

1. Configuracion Inicial (Semanas 1-2): Inicializacion del repositorio local, configuracion de credenciales y vinculacion con el servidor remoto en GitHub.
2. Estrategia de Ramificacion (Semanas 3-4): Creacion de ramas independientes (feature-design y feature-logic) para permitir el desarrollo en paralelo del diseño y las funciones sin alterar la rama principal main.
3. Gestion de Conflictos (Semana 5): Simulacion coordinada de un conflicto de fusion en el archivo app.js al modificar la misma linea de codigo desde dos ramas distintas, procediendo con la resolucion manual directamente en el sistema de control de versiones.
4. Integracion Final (Semana 6): Consolidacion del flujo basico de trabajo, revision de commits e integracion del codigo estable en la rama main para su evaluacion.
